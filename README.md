# Flutter User Input and Basic Interaction — Lab Sheet 3

**AIM:** To understand and implement user input, buttons, basic interaction, and simple dynamic UI in Flutter.

## How to run
1. Create a Flutter project:
   ```bash
   flutter create flutter_lab_sheet_3
   ```
2. Open the project folder in VS Code or Android Studio.
3. Replace `lib/main.dart` with any program file from this repository.
4. Run:
   ```bash
   flutter run
   ```

## Programs
Each `program_XX_*.dart` file is a complete standalone Flutter app. Use **one file at a time** as `lib/main.dart`.

- Programs 1–25 match the lab sheet questions.
- These are source files, not a full generated Flutter project. The standard Android/iOS/web platform folders are created by `flutter create`.
